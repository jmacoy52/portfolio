GetEduVate

Live multi-school management platform for private KG–JHS schools in Ghana. Built on a Laravel SaaS foundation. As Platform Lead, I refactored, customised and rebranded the codebase, deployed it, and run it in production with root server access and the super admin.

  • Multi-tenant: one database and subdomain per school
  • Students, attendance, fees and printable receipts
  • Exams, results and report cards
  • A public website for every school
  • Self-managed VPS: Nginx, PHP 8.3, MySQL 8, Cloudflare

EmploCore

Production-ready employee management product with secure sign-in, role-based access and an audit trail. React 19 + React Router + Axios (plain CSS) frontend on Vercel, Node.js/Express REST API on Render, MySQL 8 on Aiven over TLS.

  • JWT + bcrypt auth with server-side logout
  • Admin, HR and Employee roles; account activation and admin password reset
  • Departments management and audit logs
  • REST API with validation, rate limiting and Helmet
  • Raw SQL via mysql2, versioned migrations, automated tests
